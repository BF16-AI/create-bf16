# `create-bf16`

Scaffold a ready-to-run TypeScript, Node.js, or Next.js starter pre-wired to **[bf16.ai](https://bf16.ai)** (uncensored 1M-context LLM API, Zero Data Retention, OpenAI + Anthropic + Responses APIs).

## Usage

```bash
# Default: TypeScript + Vercel AI SDK + bf16-ai-sdk-provider
npm create bf16 my-app

# Zero-dependency Node.js starter
npm create bf16 my-script -- --template=node

# Next.js App Router streaming chat starter
npm create bf16 my-web-app -- --template=nextjs
```

## Coding Agents

Want to run Claude Code, Codex, OpenCode, or Goose on bf16.ai right now?

```bash
npx bf16ai claude
```
